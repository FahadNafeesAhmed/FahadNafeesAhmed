## Selected projects

**[Adaptive Neural Facial Deformer](https://github.com/FahadNafeesAhmed/adaptive-neural-facial-deformer)**

Recovers facial expression, head pose, and identity from partial 3D scans using a point transformer and non-rigid ICP refinement. Exports editable OpenUSD rigs. Includes trained weights, evaluation results, and comparisons with a classical solver.

Python, PyTorch, CUDA, OpenUSD

**[Periscope](https://github.com/FahadNafeesAhmed/periscope)**

Browser-based competitor research that collects pricing and product information from interactive pages, with source evidence attached to extracted facts. Built with Steel cloud browsers and Playwright.

TypeScript, Node.js, Next.js, SQLite

**[Crucible](https://github.com/FahadNafeesAhmed/Crucible)**

An experimental review-authenticity system in which agents generate adversarial examples, detect suspicious reviews, and revise detection rules from failure traces. Uses Arize Phoenix for tracing and rule storage.

Python, Gemini, Google ADK, Arize Phoenix

**[Sentinel KYC](https://github.com/FahadNafeesAhmed/sentinel-kyc-research)**

Liveness and anti-spoofing research combining physiological signals, depth consistency, and frequency-domain image analysis. Includes an interactive dashboard for inspecting individual signals.

Python, OpenCV, MediaPipe, NumPy, SciPy

**[FIAB](https://github.com/FahadNafeesAhmed/-FIAB-Failure-Injection-Agent-Benchmark-)**

A simulated GPU-node environment for studying fault diagnosis with threshold, statistical, and LLM-based agents. The evaluation harness is in development.

Python, FastAPI, React, Prometheus
